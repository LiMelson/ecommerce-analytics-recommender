# 后端（待实现）

本目录预留给 Python + FastAPI 后端。目前没有可启动的后端服务、数据库结构或已经实现的 API。

首版计划完成：

1. 数据集版本与行为明细查询。
2. 首页统计、趋势、漏斗、RF、留存、排行及画像查询。
3. 加载离线训练产物和 ID 映射，为匿名用户返回推荐结果。
4. 统一参数校验、错误处理与必要日志。

接口计划使用 `/api/v1` 前缀，建议列表见 [后端开发清单](../docs/后端开发清单与Kaggle数据集调研.md)。实现前先确认完整请求与响应结构；不要将建议路径视为已上线接口。

模型训练先由独立脚本执行，查询推荐不触发训练。首版算法配置由开发团队固定。

开始实现时，请一并补充依赖清单、`.env.example`、数据库初始化方式、服务启动命令和相关验证。示例配置中不填写真实密码。
