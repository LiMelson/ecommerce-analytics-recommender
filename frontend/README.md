# 前端工作台 · v0.2

Vue 3 + Vite + ECharts，界面已接入 FastAPI。账号、数据集、明细、统计、画像、留言与日志从后端读取并保存，刷新不再恢复原演示环境。

## 启动

推荐 Node.js 24。先按 [后端说明](../backend/README.md) 启动 MySQL、ClickHouse、API 和 worker。

从仓库根目录：

```sh
cd frontend
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173/>，使用管理员创建的账号登录。首次管理员信息在本机 `backend/instance/first-admin.txt`，不要上传或转发该文件。Vite 把 `/api` 代理到本机 8000；需要其他地址时使用本地 `VITE_API_BASE` 配置并确认后端允许来源。

## 验证

```sh
npm test
npm run test:ui
npm run build
```

Node 测试验证原有统计、CSV 辅助函数；Vitest + Happy DOM 验证真实接口页面的数据渲染、登录错误、权限菜单、导入保留原文件以及算法未接入状态。实际服务和数据库由后端集成测试与浏览器验收验证。构建产物在 `dist/`，不提交 Git。

## 已接通的页面

- 登录、退出、会话恢复、修改个人资料与密码。
- 首页、大屏、日/小时趋势、顺序漏斗、RF 分群、留存、购买排行。
- 服务端行为查询、分页、后台导出、CSV/Parquet 导入和数据版本切换。
- 管理员提交服务器目录中的大文件、任务状态与导出下载。
- 匿名用户搜索与画像，推荐查询和真实模型接入状态。
- 系统账号创建、编辑、角色分配、启停、密码重置和角色权限。
- 留言发布与处理标记、持久化操作日志。

前端菜单按权限隐藏，服务端仍独立执行每次请求的权限校验。系统账号与匿名行为用户分开管理；没有公开注册。

## 数据口径和边界

所有统计使用页面选择的数据版本，图表显示汇总数据，不把全量行为加载到浏览器。行为表默认筛选最近七天，关键词精确匹配用户或商品 ID；用户选择器按 ID 前缀查找。排行榜显示前 20，画像近期记录取最近 20、页面展示其中 5 条。

首页漏斗比较事件量；分析页漏斗要求同用户、同商品、时间严格递增。RF 没有金额 M；留存以样本首现日期分组，不代表注册日期；类目分布按行为次数统计。

前端不再选择推荐算法或训练超参数，不运行假训练。算法组服务尚未接入时提示未就绪，不生成虚构推荐。推荐原始分数不解释为概率。

`src/data/behavior.js` 中仍保留早期演示数据生成与纯计算函数，供测试及显式生成联调样本使用；当前工作台不以这些函数替代后端。`src/data/csv.js` 保留导出辅助函数及旧解析器测试，上传流程直接发送原文件，不在浏览器去重或清洗。
