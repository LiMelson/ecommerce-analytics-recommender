# 电商用户行为分析与精准推荐系统 · 前端展示

根据用户提供的三张参考截图实现，采用 Vue 3、Vite 和 ECharts。当前版本用于确认界面、模块边界及交互流程，尚未连接数据库、身份认证或真实推荐模型。

## 启动

需要 Node.js 20.19+ 或 22.12+；当前环境使用 Node.js 24。

从仓库根目录执行：

```sh
cd frontend
npm ci
npm run dev
```

浏览器打开 `http://127.0.0.1:5173/`。开发服务器支持保存代码后自动更新。

```powershell
npm test
npm run build
npm run preview
```

构建产物位于 `dist/`，可部署到静态站点服务器。`npm run preview` 默认地址为 `http://127.0.0.1:4173/`。

## 已有页面与交互

- 首页：核心统计、每日行为趋势、事件总量漏斗、快捷入口。
- 数据大屏：集中展示指标、趋势和热门类目。
- 数据分析：每日趋势、每时趋势、顺序转化漏斗、RF 分群、留存矩阵、类目与商品排行。
- 智能推荐：用户选择、方案选择、生成前端推荐、查看商品明细、查看用户画像、训练任务流程演示。
- 数据管理：行为查询、类型和日期筛选、分页、CSV 导入、CSV 导出、字段说明、恢复演示数据。
- 日志管理：当前会话中的导入、推荐及任务演示日志。
- 系统留言：发布留言、切换处理状态。
- 系统管理：账号添加与编辑、启停展示、角色权限矩阵。
- 个人信息：修改本次会话中的显示资料。
- 通用：折叠侧栏、多页签打开与关闭、面包屑、详情弹窗、反馈提示。

## 数据与功能边界

默认行为记录全部由可复现的虚构样本生成，统计、画像、排行、留存与顺序漏斗由这些记录计算。

CSV 导入最多 10 MB、25,000 条，支持有表头文件与天池格式的无表头五列文件。导入会替换当前会话的数据，并更新相关分析。当前版本不持久化导入文件、留言、账号或个人信息，刷新页面恢复演示环境。

RFM 页面目前使用 R（距样本最后时刻的购买间隔）和 F（购买事件频次），没有金额字段，M 明确显示缺失。“首次出现留存”是样本中的首次观察日期，不是注册日期。

首页漏斗展示事件总量；漏斗分析页按同用户、同商品的浏览 → 加购 → 购买时间顺序计算，两者口径不同。

“BPR”是后续模型方案入口。当前推荐由类目兴趣、行为权重、时间衰减及商品热度生成前端预览，未训练 BPR 或计算真实购买概率。模型训练按钮只演示状态流转。账号与权限功能也只改变前端展示数据，不提供安全鉴权。

## 后续接入位置

| 位置 | 后续替换内容 |
| --- | --- |
| `src/data/behavior.js` | 拆分为后端统计、用户画像与推荐接口 |
| `src/data/csv.js` | 保留模板和前端检查，导入转交后端任务 |
| `src/data/charts.js` | 保留图表配置，将数据源改为 API 返回值 |
| `src/App.vue` 的 `generateRecommendation` | 调用用户推荐接口 |
| `src/App.vue` 的 `startTraining` | 创建任务、轮询状态、读取模型版本 |
| 账号、权限、留言和日志 | 接入认证、授权与持久化服务 |

建议接口按 `/api/v1/overview`、`/api/v1/analytics/*`、`/api/v1/users/:id/profile`、`/api/v1/recommendations`、`/api/v1/datasets` 分组。这里仅记录约定方向，当前前端不调用这些接口。

最新首版约定：算法与训练参数由开发团队固定，网站操作人员选择匿名用户并获取推荐。当前界面仍有方案选择与训练参数演示入口，后续接入时需移除这些选择。训练先由开发者运行脚本；若后续保留管理员一键训练，使用服务端固定配置，训练任务在独立进程中执行。当前前端代码尚未按此约定调整。

已将购物车、订单、支付等交易系统功能排除在本项目范围之外。
