# 推荐算法与实验（待实现）

本目录用于数据适配、离线训练、评估与模型导出。目前没有真实训练代码或模型权重，前端的推荐结果来自演示规则。

2026-11-16 接入更新：前端现在调用真实后端，模型未接入时显示未就绪，不再运行前端演示推荐。算法组交付推理服务后可按 [数据与算法交付约定](../docs/数据与算法交付约定.md) 接入；后端已提供版本登记、兼容性校验和推理 HTTP 适配。

计划先完成热门推荐与 ItemCF，再训练 BPR；最终算法根据统一协议下的验证结果决定，不预设复杂模型一定更好。

训练与评估需要统一：

- 推荐目标、数据版本、清洗规则与固定实验样本。
- 按全局时间划分训练、验证与测试窗口；预测使用的统计和特征不包含未来数据。
- 候选商品、已交互商品过滤、负采样与冷启动规则。
- Recall@10、NDCG@10、覆盖率及推荐耗时，并说明有效评估用户范围。
- 随机种子、依赖版本、参数配置与实验结果。

导出产物应至少包含模型、用户与商品 ID 映射、数据版本、训练截止时间、配置和评估摘要。后端按约定格式加载产物，前端不传学习率、训练次数或算法选择。

实际数据和模型产物保留在本地，建议使用根目录 `data/` 与 `artifacts/`，并遵循 [数据说明](../data/README.md)。
