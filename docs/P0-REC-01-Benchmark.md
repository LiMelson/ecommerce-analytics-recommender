# P0-REC-01 未来购买 Benchmark 协议

协议版本为 `purchase_global_utc_v1`。在统一预测时刻，模型读取该时刻之前的行为，为用户推荐随后固定窗口内可能购买的商品。协议适用于热门、后续 ItemCF 和 BPR。配置及实际窗口统计见 [运行配置](../recommendation/popular_v1.json) 和 [真实运行记录](../recommendation/reports/p0-rec-01-benchmark.json)。

## 时间与训练

在约定观测区间 [2019-10-01 00:00, 2019-12-01 00:00) UTC 内，按经过时间的 0%、70%、85%、100% 确定边界。半开区间包含起点，排除终点。正好出现在边界的事件进入后一个窗口。样本中实际首末事件时间由数据验收单独记录。

| 窗口 | UTC 起点（含） | UTC 终点（不含） | 可用拟合数据 |
| --- | --- | --- | --- |
| 训练 | 2019-10-01 00:00 | 2019-11-12 16:48 | 为验证拟合 |
| 验证 | 2019-11-12 16:48 | 2019-11-21 20:24 | 训练 |
| 测试 | 2019-11-21 20:24 | 2019-12-01 00:00 | 方案冻结后，以训练和验证重新拟合 |

每个预测窗口只评分一次，窗口内用户历史、类目、购买热度、商品集合和已买集合全部冻结。验证用于选择参数。测试用于汇报已冻结方案，未来模型使用相同切分和重训规则。本轮热门规则没有调参；验证快照为 `popular_v1_validation`，测试快照为 `popular_v1`。

## 候选与目标

- 截止点前至少出现一次的商品进入全量候选。样本没有库存、上下架或商品主数据，已出现是本阶段的可用性代理。候选不使用验证或测试结果筛选。
- 对每个用户，统一过滤截止点前买过的商品。浏览或加购过的商品仍可推荐。购买次数用于热门计分，购买标签按用户和商品去重。
- 未来窗口内的全购买标签分成三类：符合候选规则的目标、截止后首现的新商品、截止前已购买的复购商品。三类互斥。复购和新商品均不进入主口径分母。窗口内重复买同一商品形成一个目标，同时保留原始购买事件数。
- 全量候选评测不做负采样。ItemCF 可以从邻居生成较短的推荐列表，BPR 可以在拟合时采样训练负例；评估器仍使用同一可用商品集合、评估用户和标签。

## 用户队列及冷启动

评估器遍历窗口内出现过的全部用户，包括没有购买记录的用户。用户是否购买是事后统计，其历史频次与推荐在预测时刻冻结。未来窗口内从未出现的用户没有纳入这份离线队列。

主指标的有效用户是在窗口内至少有一个符合候选规则的购买目标者。无有效目标人数拆成窗口内无购买、购买目标全部不可达两类。附加全购买目标口径覆盖每位窗口购买用户，并保留复购和新商品在分母。只有不可达目标的购买用户在该口径得零分。无购买者保留在计数和覆盖率的全用户口径。

仅在初始训练窗口内，对有历史用户的事件数取 nearest-rank 分位数。观测值升序排列后取第 ⌈p × n⌉ 项。本次 P25 = 2，P75 = 15。阈值在测试之前固定。验证使用训练期事件数，测试使用训练与验证期事件数。

| 分组 | 截止前事件数 |
| --- | ---: |
| 冷启动 | 0 |
| 低频 | 1–2 |
| 中频 | 3–15 |
| 高频 | ≥16 |

测试里同时保留最初训练期已见人数和最终拟合已见人数。商品首现也按对应预测截止点单独计数，分别记录窗口首现商品、已被购买的首现商品、其购买事件和用户商品对。

## 指标

对用户 u，令 T 为该口径下去重后的购买目标集，L 为按首次出现位置去重后截取的前 K 项，H 为 L 与 T 的交集。

| 指标 | 单用户公式或覆盖率公式 |
| --- | --- |
| Recall@K | \|H\| ÷ \|T\| |
| NDCG@K | DCG ÷ IDCG，DCG = Σᵣ relᵣ ÷ log₂(r+1)，relᵣ 在第 r 位命中时为 1，其余为 0。IDCG 将 min(K, \|T\|) 个命中排在最前 |
| Precision@K | \|H\| ÷ K |
| HR@K | 命中任意购买目标为 1，否则为 0 |
| 商品覆盖率 | 指定用户范围内进入推荐列表的去重商品数 ÷ 截止前候选商品总数 |

前四项对有效用户做等权宏平均。主指标是 Recall@10 和 NDCG@10。空目标用户只进入对应计数；有目标但推荐为空按零分计入。候选不足 K 时返回实际条数，Precision 的分母仍为 K。没有有效用户时宏平均为 JSON null，候选目录为空时覆盖率为 null。主覆盖率使用有效用户，其余覆盖率以窗口内全部用户计算。模型若在 TopK 返回越过候选规则的商品，评估直接报错。

## 热门排序与来源

候选按截止前购买事件数降序排列，同分按商品 ID 字符串升序。零购买商品排在正分商品之后。类目采用截止前最近一个已知类目，同时刻按类目字符串升序；无已知类目返回空字符串。请求仅扫描预构建榜单并使用该用户的过滤集合。无历史时沿用同一热门榜，并标记兜底来源。模型分数表示购买事件次数。

验证和测试共用一个评估器。报告保存训练截止、数据及代码指纹、两类推荐来源人数、每个窗口排序的整体 SHA-256 和汇总指标。随机种子不参与这个确定性算法。数据生产的抽样规则另见数据验收。
