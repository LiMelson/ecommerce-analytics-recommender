# 进度说明（2026-11-16）

## 可直接发群的版本

【数据处理进度 · 11月16日】

已完成：

1. 主数据集定为天池 220316（真实电商点击流，2019-10/11），全量 1.0995 亿行，按校验规则 0 无效；
2. 按用户抽 1%（52,687 人 / 107.9 万条），保留完整历史，固定种子可复现；
3. 完成概览、每日/每时趋势、顺序漏斗、RFM、用户画像、留存、购买排行、购物车放弃；
4. 13 个测试通过；DuckDB 全量扫描 + 抽样约 3.5 分钟。

关键结果：

- 漏斗：浏览 555,180 → 加购 20,596（3.71%）→ 购买 8,486（41.20%）
- RFM：有购买 6,976 人；高频活跃 430 人；潜在转化 45,711 人
- 留存：次日 10.92%，第 7 日 5.49%
- 购买类目 Top1：手机 7,456 次，占金额 68.07%
- 购物车放弃率：59.19%

产出：

- 代码/说明：`data_algo/`
- 聚合结果：`data_algo/reports/`
- 选型与口径：`docs/数据选型与处理说明.md`

口径提醒：金额是行为口径，不是 GMV；没有年龄/性别；没有收藏；留存是样本首现留存；原始 UTC、统计按北京时间。
