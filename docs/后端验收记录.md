# 后端验收记录

日期：2026-11-16。本记录区分已执行验证与容量设想。推荐训练、数据清洗、真实业务数据质量与线上效果不在本轮范围内。

## 已执行的验证

- 业务模块测试：会话、密码哈希、CSRF、请求来源、角色权限、停用与密码变更后会话撤销、自己/最后管理员保护、分页、留言归属和资料持久化。
- 导入测试：UTF-8 CSV、Parquet、类型和时间验证、目录越界拒绝、重复事件保留、失败版本不发布、中断任务不晚到发布。
- 真实 MySQL + ClickHouse：通过随机隔离库验证导入、汇总、严格漏斗、跨日统计、RF、留存、画像、注入样式搜索字串、导出、版本切换和并发任务领取。
- 算法适配测试：固定请求配置、版本一致性、响应排序与唯一性；未接入返回真实 503，不伪造结果。
- 前端：纯函数测试、API 接入页面回归和生产构建；实际浏览器检查登录、账号编辑、权限矩阵、分群、画像、未接入推荐、CSV 提交、刷新持久化与版本切换。

最终测试数量以提交前终端记录及 GitHub Checks 为准，检查命令见 backend/README.md、frontend/README.md。普通 CI 不执行慢速百万行测试。

本轮提交前已通过 23 项常规后端测试（包含 3 项真实数据库集成）、6 项前端纯函数测试、5 项页面接入测试及生产构建，Ruff 与 Alembic 结构一致性检查通过；百万行测试另行执行通过。

## 百万条生成数据测试

环境：Windows 本机约 16 GB 内存，MySQL 8.0.42，Docker ClickHouse 26.8.37.168，容器限制 3 GiB/2 CPU。测试使用临时隔离库、100 万条生成事件、约 1 万用户、5000 商品、30 类目，源 CSV 为 36,000,051 字节；不是 Kaggle 全量，也不是推荐算法数据质量测试。

| 项目 | 本次实测 |
|---|---:|
| 分批入库并生成汇总 | 196.794 秒 |
| Python tracemalloc 追踪的分配峰值 | 23.35 MiB |
| 概览查询 | 0.075 秒 / 1,123 字节响应 |
| 留存查询 | 0.445 秒 / 140 字节响应 |
| RF 分群查询 | 0.074 秒 / 103 字节响应 |
| 10 条行为明细查询 | 0.136 秒 / 1,039 字节响应 |
| 指定用户画像查询 | 0.207 秒 / 2,148 字节响应 |

导入时间包含 Python tracemalloc 开销；峰值只表示被追踪的 Python 分配，不包含全部进程 RSS、MySQL、ClickHouse、浏览器或 Docker 内存。查询通过本地 ASGI 测试客户端，不含公网、真实浏览器网络与大并发；数字是单次样本，不作为服务 SLA。之后对无关键词明细的总数查询改用日汇总，轻量集成测试另行验证。
