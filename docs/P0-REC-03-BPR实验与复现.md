## BPR 与 ItemCF 的区别

ItemCF 保存商品之间的共现邻居，使用用户历史商品的邻居贡献生成分数。BPR 学习每位可训练用户与每件候选商品的短向量，使用向量内积表示排序偏好。向量中的数由训练学得，不能直接把某一维命名为真实人口属性或商品语义。

本轮使用现有 NumPy、SciPy 实现 CPU 训练，沿用 Python 3.12 锁定依赖。每个批次收集用户、正商品、负商品向量副本计算梯度，用 `np.add.at` 正确累加重复索引。训练只分配用户×维度、商品×维度向量和正负样本批次。模型状态完成后以不可变字节保存，保证请求不会改动共享历史或因子。

### 正负样本与损失

以截止前购买事件中的去重用户商品对作正样本。重复购买只形成一对，每一 Epoch 每对均匀出现三次，分别抽取负例。负例允许重复，来自同一截止点的全量已知目录，排除该用户的全部训练购买正样本。浏览但未购买的商品仍可能被抽为负例，负例只代表尚未观察到购买。采样先作均匀拒绝采样，遇到极密集用户时改为在显式补集中均匀抽取。完全没有补集的用户跳过训练并保留在推荐和评估中。

设用户向量为 pᵤ，正商品和负商品向量为 qᵢ、qⱼ。

- 偏好分数为 s(u,i) = pᵤ · qᵢ。
- 排序差为 Δ = pᵤ · (qᵢ − qⱼ)。
- 单三元组损失为 **log(1 + exp(−Δ)) + λ/2 × (‖pᵤ‖² + ‖qᵢ‖² + ‖qⱼ‖²)**。
- 令 g = sigmoid(−Δ)，用户梯度步为 η[g(qᵢ−qⱼ)−λpᵤ]，正商品为 η[gpᵤ−λqᵢ]，负商品为 η[−gpᵤ−λqⱼ]。

代码用 `logaddexp` 和 `expit` 稳定计算。每批对各三元组梯度求和，向量共享更新由 `add.at` 累积。报告的损失按三元组均值显示。一次 Epoch 表示全部去重正样本对按固定种子洗牌、各取指定数量负例后走完一次训练。每轮同时保存新抽样的训练损失，以及固定训练诊断负例上的损失。诊断负例来自训练目录，用独立种子生成，不含验证或测试标签。

### 三用户五商品的手算

假设甲买 A、B，乙买 B、C，丙买 D，E 只有浏览。目录含 A–E，训练有 5 个去重购买对。甲的负例来自 C、D、E。对甲、A、C 的某一步，取二维中间向量 p=[1,0]，q_A=[0.2,0.1]，q_C=[0.1,0.3]，则 Δ=0.1。η=0.1、λ=0.01 时，损失约为 0.65015。

g 约为 0.47502。按公式同步计算后，p′≈[1.00375,−0.00950]，q_A′≈[0.24730,0.09990]，q_C′≈[0.05240,0.29970]。同一个三元组的新损失约为 0.60511，正商品相对负商品的排序差扩大。实际程序从固定种子的随机初值开始，这组数用于人工演示其中一步。

推荐甲时仍过滤他已经买的 A、B，再对 C、D 等有正反馈信号的商品打分。E 缺少任何正向购买训练信号，按热门补位处理。模型不能凭 E 的随机初始向量给它一个 BPR 推荐分。

## 统一规则与兜底

评估继续使用 `purchase_global_utc_v1`。验证拟合 2019-10-01 00:00 至 11-12 16:48 UTC，目标为此后至 11-21 20:24。最终拟合延长至 11-21 20:24，测试目标至 12-01 00:00。窗口左闭右开，阈值固定为初始训练 P25=2、P75=15。候选是截止前已见商品，按完整历史过滤已购，主标签是可达的去重未来购买对。全部购买口径同时保留新商品与复购的不可达目标。

BPR 只能对可训练购买用户使用隐向量。有历史但没购买者使用 `popular_no_bpr_positive`，完全新用户使用冷启动热门来源，正样本覆盖目录而没有负例者使用 `popular_no_trainable_vector`。因子异常或分数非有限时走 `popular_invalid_bpr_score`。没有有效购买训练信号的商品进入热门补位，完整候选资格和评估分母保持一致。

按 BPR 内积降序、商品字符串 ID 升序取有信号且未买的商品，不足时按同一历史热门榜补齐并排重。返回列表位置定义最终 rank，BPR 分数与热门次数不可跨来源比较，也不可解释为购买概率。没有购买记录者照常保留在全用户计数与各指定评估口径中。

## 局限与后续审查

购买正反馈很稀疏，最终拟合只有 6,235 个可训练购买用户，大多数预测请求仍依赖热门。在低中频组，BPR 混合结果比 ItemCF 好；高频组则明显下降。买过商品全部过滤，使训练中已观察的偏好商品在未来推荐中被排除，这符合协议，也提高了泛化要求。均匀负采样以大量长尾商品为负例，训练损失可以快速下降，未必改善热门购买商品之间的排序。这些是对观察结果的解释假设，尚无消融证据。

本轮只比较买行为的基础 MF，三组网格规模有限，单个固定种子不能量化统计不确定性。候选没有库存状态，匿名取模样本也限制了外推。BPR 成功完成训练与保存加载，并不构成网站接入或线上效果的证据。FR08 的完整任务队列、发布和回退验收仍需后续与组长联调。本轮保持当前结果，待独立审查后再决定后续试验。
